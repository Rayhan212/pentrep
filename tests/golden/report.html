Affected assets

  • https://portal.acme.example/api/v1/login

Description

The username field of the JSON login request is concatenated into a SQL query without parameterisation.

Impact

An unauthenticated attacker can bypass authentication as any user, including administrators, and read or modify the entire database.

Steps to reproduce

  1. Send the request shown in Evidence 1 to /api/v1/login.
  2. Observe that a valid session for the admin user is returned.

Evidence

Remediation

Use parameterised queries (prepared statements) for all database access and add a WAF rule as defence in depth until the fix is deployed.

References

  • https://owasp.org/www-community/attacks/SQL_Injection
  • https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html

PT-002: Reflected Cross-Site Scripting in Search

Severity
Medium
CVSS 3.1 score
6.1 (Impact 2.7, Exploitability 2.8)
Vector
CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N
Status
Open
CWE
CWE-79

Affected assets

  • https://portal.acme.example/search?q=

Description

The q parameter is reflected into the results page without output encoding, allowing arbitrary JavaScript to run in the victim's browser.

Impact

An attacker who tricks a logged-in user into opening a crafted link can perform actions as that user and read data shown in the page.

Steps to reproduce

  1. Log in as any user.
  2. Open https://portal.acme.example/search?q=<svg/onload=alert(document.domain)>.
  3. Observe the alert box showing portal.acme.example.

Evidence

Remediation

Apply context-aware output encoding to all reflected input and deploy a Content-Security-Policy that disallows inline scripts.

References

  • https://owasp.org/www-community/attacks/xss/
